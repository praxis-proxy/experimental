What this demo proves — a scoped MVP slice of ai#658, exercised on a two-instance stack.

  1. Cross-instance enforcement: app-a's budget, exhausted on Gateway A, is denied on Gateway B too.
  2. Per-app isolation: app-b's and app-c's budgets are untouched by app-a's exhaustion.
  3. Reservation-based admission: each admitted request reserves its estimated cost up front, atomically, via the shared ledger.
  4. Automatic window recovery: app-a's budget recovers on its own once its reservation ages out of the sliding window — no manual reset.
Scope: two gateway replicas, one Valkey instance, no Grid, no multi-cluster routing, no authentication. See the demo README for what's explicitly out of scope.
